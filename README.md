# Northstar Databases and Analytics Assignment
This repository contains the Google Colab notebooks used for the Northstar case study assignment.

## Contents
- Python_Data_Processing.ipynb: data cleaning, merging, feature creation, business analysis.
- R_in_SQL_analyse.ipynb: SQL queriese in R and R visualisations.
- MongoDB_Implement.ipynb: CSV to JSON conversion, MongoDB Atlas insertion, CRUD, aggregation, indexing.

## Tools Used
- Python / pandas
- R / SQL
- MongoDB Atlas
- PyMongo
- Google Colab
